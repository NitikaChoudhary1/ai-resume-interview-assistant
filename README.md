# AI Resume + Interview Assistant

An AI-powered web application that analyzes resumes against job descriptions, calculates ATS match score, identifies missing skills, generates resume improvements, creates interview questions, and provides mock interview feedback using typed or voice answers.

## Features

- PDF/DOCX Resume Upload
- ATS Match Score
- Missing Skills Detection
- Strong Keywords
- Weak Resume Sections
- Resume Improvement Suggestions
- AI Resume Tailoring
- HR / Technical / Behavioral Questions
- STAR Format Answers
- Mock Interview Feedback
- Voice-Based Interview Analysis

## Tech Stack

- Python
- Flask
- JavaScript
- HTML/CSS
- SpeechRecognition
- pdfplumber
- python-docx
